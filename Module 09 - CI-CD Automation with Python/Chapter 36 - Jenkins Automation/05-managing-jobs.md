# Managing Jenkins Jobs: Configuration as Code

In large organizations, manually configuring Jenkins jobs through the web UI is inefficient. It leads to configuration drift, makes backing up settings difficult, and increases human error. A better approach is to manage configurations programmatically.

Jenkins stores its job configuration settings internally as XML files. Using `python-jenkins`, you can create new jobs, fetch and modify existing XML configurations, copy jobs from templates, organize jobs into folders, and delete old configs using Python code.

In this guide, we will write a script to create, update, and delete Jenkins jobs programmatically using XML configurations, and organize them into directories.

---

## The Jenkins XML Configuration Structure

Every Jenkins job type (Freestyle, Pipeline, Folder) has a corresponding XML schema. Here is the standard XML template for a **Jenkins Declarative Pipeline** job:

```xml
<?xml version='1.1' encoding='UTF-8'?>
<flow-definition plugin="workflow-job">
  <actions/>
  <description>Automated Pipeline Job generated by Python configuration manager.</description>
  <keepDependencies>false</keepDependencies>
  <properties>
    <org.jenkinsci.plugins.workflow.job.properties.DisableConcurrentBuildsJobProperty/>
  </properties>
  <definition class="org.jenkinsci.plugins.workflow.cps.CpsScmFlowDefinition" plugin="workflow-cps">
    <scm class="hudson.plugins.git.GitSCM" plugin="git">
      <configVersion>2</configVersion>
      <userRemoteConfigs>
        <hudson.plugins.git.UserRemoteConfig>
          <url>https://github.com/my-company/my-project.git</url>
          <credentialsId>github-deploy-key</credentialsId>
        </hudson.plugins.git.UserRemoteConfig>
      </userRemoteConfigs>
      <branches>
        <hudson.plugins.git.BranchSpec>
          <name>*/main</name>
        </hudson.plugins.git.BranchSpec>
      </branches>
      <doGenerateSubmoduleConfigurations>false</doGenerateSubmoduleConfigurations>
      <submoduleCfg class="empty-list"/>
      <extensions/>
    </scm>
    <scriptPath>Jenkinsfile</scriptPath>
    <lightweight>true</lightweight>
  </definition>
  <triggers/>
  <disabled>false</disabled>
</flow-definition>
```

## 1. Creating and Updating Jobs

To create or update a job, use the `create_job()` or `reconfig_job()` methods, passing the configuration XML string.

```python
import jenkins

server = jenkins.Jenkins("http://localhost:8080", username="admin", password="token")
job_name = "billing-api-pipeline"

# Template XML config string
config_xml = """<?xml version='1.1' encoding='UTF-8'?>
<flow-definition>
  <description>Auto-generated pipeline</description>
  <definition class="org.jenkinsci.plugins.workflow.cps.CpsFlowDefinition">
    <script>
      pipeline {
        agent any
        stages {
          stage('Test') {
            steps {
              echo 'Running automated tests...'
            }
          }
        }
      }
    </script>
    <sandbox>true</sandbox>
  </definition>
</flow-definition>"""

try:
    # 1. Check if the job already exists
    if not server.job_exists(job_name):
        print(f"Creating new job: {job_name}...")
        server.create_job(job_name, config_xml)
        print("✅ Job created successfully.")
    else:
        # 2. Update existing job configuration
        print(f"Job '{job_name}' already exists. Reconfiguring...")
        server.reconfig_job(job_name, config_xml)
        print("✅ Job reconfigured successfully.")
        
except Exception as e:
    print(f"Failed to manage job: {e}")
```

## 2. Reading Existing XML Configs

To back up configurations or make automated search-and-replace changes, retrieve the raw XML config string using `get_job_config()`.

```python
import jenkins

server = jenkins.Jenkins("http://localhost:8080", username="admin", password="token")
job_name = "billing-api-pipeline"

try:
    # Fetch XML string
    xml_data = server.get_job_config(job_name)
    
    # Save config to file
    with open("backup_config.xml", "w", encoding="utf-8") as f:
        f.write(xml_data)
        
    print("✅ Configuration XML downloaded and backed up.")
except Exception as e:
    print(f"Failed to fetch config: {e}")
```

## 3. Organizing Jobs with Folders

In enterprise environments, jobs are organized into folders (e.g. by team or environment). In Jenkins, a folder is simply a job configured with a folder class. 

To create nested jobs:
1. Create a job of type `com.cloudbees.hudson.plugins.folder.Folder`.
2. Reference the job using slash notation (e.g., `folder_name/job_name`).

```python
import jenkins

server = jenkins.Jenkins("http://localhost:8080", username="admin", password="token")

# XML template to define a Jenkins Folder
folder_config_xml = """<?xml version='1.0' encoding='UTF-8'?>
<com.cloudbees.hudson.plugins.folder.Folder>
  <description>Engineering team sandbox folder</description>
  <properties/>
  <folderViews/>
</com.cloudbees.hudson.plugins.folder.Folder>"""

folder_name = "backend-team"
nested_job_name = f"{folder_name}/api-checks"

try:
    # 1. Create the parent folder if it doesn't exist
    if not server.job_exists(folder_name):
        server.create_job(folder_name, folder_config_xml)
        print(f"✅ Folder '{folder_name}' created.")
        
    # 2. Create the job inside the folder
    job_config_xml = "<flow-definition><description>Nested Job</description></flow-definition>"
    
    if not server.job_exists(nested_job_name):
        # We pass the full path folder_name/job_name
        server.create_job(nested_job_name, job_config_xml)
        print(f"✅ Nested job '{nested_job_name}' created.")
        
except Exception as e:
    print(f"Failed to manage folders/nested jobs: {e}")
```

## 4. Copying and Deleting Jobs

Copying is useful when generating jobs from stable templates. Deleting removes obsolete configurations.

```python
import jenkins

server = jenkins.Jenkins("http://localhost:8080", username="admin", password="token")

# Copy template-job to create sandbox-build
try:
    if server.job_exists("template-job"):
        server.copy_job("template-job", "sandbox-build")
        print("✅ Copied job successfully.")
except Exception as e:
    print(f"Failed to copy job: {e}")

# Delete obsolete job
try:
    if server.job_exists("sandbox-build"):
        server.delete_job("sandbox-build")
        print("🗑️ Job 'sandbox-build' deleted successfully.")
except Exception as e:
    print(f"Failed to delete job: {e}")
```
